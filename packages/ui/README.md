# @mft/ui

MyFinancialTracker's design system: tokens, fonts and React 18 components for a personal budget app.

## Use it in the app

```ts
import "@mft/ui/tokens.css"; // custom properties, Hanken Grotesk @font-face, light + dark
import "@mft/ui/styles.css"; // type scale + component styles
import { Amount, Button, Card, TransactionRow } from "@mft/ui";
```

Money is passed around as **integer minor units** (centavos). `<Amount minorUnits={125050} />` renders ₱1,250.50.

## Layout

```
src/
  tokens/tokens.ts      single source of truth for every token
  tokens/*.css          generated by `bun run tokens`; never edit by hand
  lib/                  cx, money formatting, internal icons
  components/<Name>/    <Name>.tsx · <Name>.css · README.md (guidelines) · index.ts
  index.ts              public API
  iife-entry.ts         window.MFT for the browser bundle
design-system/          brand book, previews and cover for the Design System artifact
scripts/                build-tokens.ts · build.ts (Bun.build) · export-design-system.ts
assets/                 fonts (Hanken Grotesk, OFL) and the logo mark
```

## Scripts

| Command | What it does |
| --- | --- |
| `bun run tokens` | Regenerates `src/tokens/tokens.css` and `type.css` from `tokens.ts` |
| `bun run build` | Tokens, then the ESM library, the IIFE bundle (`dist/iife/mft-ui.js`) and `.d.ts` files |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run export:ds` | Builds, then writes the Design System artifact files to `design-system-export/` |

## Conventions

- Component CSS uses tokens only (`var(--pine)`, `var(--space-4)`). No raw colors or pixel values outside `tokens.ts`.
- Class names are `mft-<component>__<part>--<modifier>` (BEM), so styles never collide with app CSS.
- Each component owns its stylesheet and imports it, and Bun bundles every stylesheet into `dist/index.css`.
